Scoring & method

Defense / Special Teams

How it's counted

  • Points allowed leaves out points the team's own offense gave up (pick-sixes, fumble-return TDs and safeties), the same way Yahoo does. Kick and punt return TDs allowed still count.
  • Return yards are kickoff and punt return yards. Each yard is worth 1/10 of a point, so 87 yards is 8.7.
  • Touchdown covers interception, fumble and blocked-kick return TDs. Kick and punt return TDs are counted separately.
  • 4th down stops are failed 4th-down runs and passes; a 4th-down turnover is scored as the turnover only.
  • Extra point returned is a blocked PAT or stopped two-point try returned for 2.

Matchup score

Half the defense's average points per game, plus half the average points its opponent has given up to defenses. "Last 3" uses only each team's three most recent games for both halves.

Where the numbers come from

Play-by-play and schedules from the public nflverse data project. The page is rebuilt every Tuesday after Monday Night Football, once that week's play-by-play is posted. Totals can differ from Yahoo by a point now and then when a stat correction lands.
